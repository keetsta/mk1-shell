# mk1-shell

шелл визитки mk-1: язык выдуманного чипа, побитый мануал, задачи. ядро на C11 без зависимостей от железа, плюс эмулятор карты для терминала.

```
make            # build/mk1, build/test, build/test-card и build/test-demo
make test       # тесты ядра, шелла, карты и демо
make run        # карта в терминале
make content    # пересобрать мануал и проверки задач из content/
```

в эмуляторе матрица нарисована сверху. пока программа работает, пробел нажимает и отпускает кнопку, `+` и `-` меняют свет, `^C` останавливает программу. стрелки ↑ ↓ листают историю команд, `cls` очищает экран, `^D` в пустой строке выходит. длинные главы `man` листаются: пробел — страница, enter — строка, `q` — хватит. панель не пропадает и после изменения размера окна. состояние лежит в `~/.mk1-shell` (или в `$MK1_STATE`).

- `src/core/`: чип (`vm`), задачи и шифрование глав (`tasks`, `sha256`), шрифт бегущей строки (`font`), шелл (`shell`), интерфейс к карте (`hal.h`)
- `src/host/`: `hal.h` для терминала Mac
- `src/card/`: прошивка карты. с железом говорят только `main.c` и `is31fl3731.c`, остальное (`face`, `own`, `prompt`, `cube`, `light`, `panel`, `store`) без железа и проверяется тестами на компе
- `demo/`: демо-прошивка для разработки, понг и кубик по кнопке. в основной прошивке их нет, см. ниже
- `tools/cardsim.c`: экраны карты на компе, кадры для `make preview` и `make preview-demo` (сценарии `tools/visit.c` и `demo/visit.c`)
- `tools/mkcontent.c`: `content/` → `src/core/content_gen.c`
- `content/`: тексты глав и эталонные решения, клон приватного `keetsta/mk1-content`. **не публиковать**, см. `SPEC.md`

спека чипа и механики: `SPEC.md`. плата: `../mk1-card`.

## прошивка карты

`src/card/`: прошивка под RP2350. ядро то же, что в эмуляторе, а `main.c` даёт ему `hal.h` на железе карты.

- шелл по USB CDC: VID 0x2e8a, как ищет keetsta.me/mk1. открыл порт: баннер и приглашение. открыл на 1200 бод: карта уходит в BOOTSEL
- матрица: IS31FL3731 по i2c0, гамма 2.2, яркость по датчику света. весь экран берёт не больше 40 % тока, чтобы драйвер не грелся
- кнопка: BOOTSEL, во время работы читается из RAM
- датчик света: два диапазона (GPIO27). порт `lux` в логарифмической шкале: 1 лк = 0, 10000 лк = 1023
- состояние шелла: кольцо из 8 секторов в конце флеша с CRC. питание пропало посреди записи: грузится прошлая запись. новая прошивка его не стирает

что карта показывает сама, без терминала (`face.c`, экраны в `own.c`):

- загрузка: по экрану проходит столбец, каждый светодиод загорается хоть раз
- ожидание: приглашение и курсор, раз в 9 секунд бежит `keetsta.me/mk1`. нажатие пускает адрес сразу, больше кнопка тут ничего не делает
- кубик: 5 минут без дела. нажатие возвращает в ожидание. час без дела: курсор медленно дышит, нажатие будит
- терминал открыл порт: две точки сходятся и расходятся кольцом, дальше экран принадлежит шеллу. `^D` возвращает экран карте до следующей клавиши, адрес тогда бежит только по нажатию. программа, запущенная перед закрытием терминала, держит экран, пока не кончится

```
make card PICOTOOL_DIR=<папка picotool>   # build/card/mk1.uf2
make preview                              # build/card-preview.mp4, нужен ffmpeg
```

для `make card` нужны pico-sdk 2.3.1 (`PICO_SDK_PATH`), Arm GNU Toolchain (`PICO_TOOLCHAIN_PATH`), cmake, ninja и picotool. залить: зажать кнопку, воткнуть кабель, скопировать `mk1.uf2` на диск `RP2350`.

## демо-прошивка

`demo/`: прошивка для разработки. карта и шелл те же, другие только экраны без терминала: `demo/own.c` вместо `src/card/own.c`. к ожиданию, кубику и сну она добавляет то, чего в основной прошивке нет:

- понг: нажатие в ожидании запускает (игра начинается, когда кнопку отпустили), кнопка поднимает ракетку. до 5 очков. выход: удержание 2 с между розыгрышами (на экране счёта, снизу заполняется полоса). посреди розыгрыша кнопка только двигает ракетку: держать её вверху долго это обычная игра
- кубик по кнопке: удержание 2 с в ожидании, снизу заполняется полоса

по USB она называется `mk-1 demo`, страница keetsta.me/mk1 видит её так же, как основную.

```
make demo PICOTOOL_DIR=<папка picotool>   # build/card/mk1-demo.uf2
make preview-demo                         # build/demo-preview.mp4
```
