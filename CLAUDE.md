# mk1-shell

прошивка визитки mk-1 и posix-эмулятор. `src/core/` также работает в wasm на [mk1-web](https://github.com/keetsta/mk1-web). аппаратная часть описана в `mk1-card/CLAUDE.md`, сборка в [README](README.md), технические контракты в [SPEC](SPEC.md).

## сборка и контент

- после изменений запусти `make test`. если доступен приватный `content/`, прогони и эталонные решения.
- `content/` содержит приватный `mk1-content`. коммить только сгенерированный `src/core/content_gen.c`. после правок контента или задач выполни `make content`. исходные файлы контента должны иметь окончания строк LF.
- интерфейс игрока и мануал пиши по-английски и строчными. любой пропуск в мануале должен выясняться через `try`.
- добавил исходник ядра или экрана карты, проверь список файлов в `mk1-web/wasm/build.sh`. обновление релиза веба собирает wasm из закреплённого коммита подмодуля.

## границы безопасности

- ядро обращается к платформе только через `hal.h`. байткод извне проверяй через `vm_decode` до выполнения. при изменении операндов синхронизируй ассемблер, декодер и тесты.
- реальные OTP, производные ключи, токены и данные регистрации не должны попадать в git, вывод инструментов или тестовые фикстуры. picotool печатает значения OTP отдельными строками, поэтому маска по имени строки не защищает их.
- `saved` должен помещаться в `HAL_STATE_MAX`. изменения формата требуют нового magic и миграции старых записей. эта же схема лежит в браузерном сохранении.

## поведение платформ

- ввод ядра ASCII. байты `0x80` и выше проверяй как `unsigned char`. история перерисовывает строку целиком. ctrl+d обрабатывает ядро через `hal_exit`.
- posix-эмулятор заново ставит область прокрутки по SIGWINCH. `man` использует `hal_rows`; на карте значение 0 оставляет прокрутку терминалу.
- прошивка использует одно ядро rp2350. чтение BOOTSEL из RAM временно освобождает CS флеша, что опасно для второго ядра в XIP. для записи используется `PICO_FLASH_ASSUME_CORE1_SAFE=1`.
- usb cdc начинает передавать данные при поднятом DTR. перезапуск на 1200 бод делает `src/card/main.c` после запуска восьми кадров заливки в драйвере матрицы. режим breath оставляй выключенным, иначе он может остаться активным после смены прошивки.
- основная прошивка по кнопке будит экран и показывает адрес. в `demo/` короткое нажатие листает пять заставок, удержание на 2 с с отпусканием запускает понг. выход удержанием только между розыгрышами. при изменении баланса используй симуляцию из `make test`.
- `face.c` оставляет экран запущенной программе после закрытия порта. край нажатия в тик возврата экрана принадлежит предыдущему режиму. `own_draw` отключает послесвечение на собственных экранах карты, чтобы сохранить чёткие буквы и движение.
- анимации проверяй по видео из `make preview`, `make preview-demo`, `make preview-savers`, `make preview-update`. терминал проверяй из pty с разными размерами, ascii-арт в моноширинном превью и с авторской атрибуцией. новый арт сначала покажи владельцу проекта.
